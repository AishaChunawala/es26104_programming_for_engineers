# 💻 ES26104 - Programming for Engineers

A comprehensive collection of foundational Python scripts, practice exercises, and college laboratory practical assignments completed for the **ES26104: Programming for Engineers** course. This repository showcases core programming concepts, control structures, loops, strings, and mathematical problem-solving.
